# Privacy Policy — Voice Proofreader API

**Effective: February 2026**

The Voice Proofreader API analyzes text you submit for AI-generated writing patterns. Your text is processed in memory and discarded immediately after the response is returned. We do not store, log, or retain any text submitted to the API. No personal data is collected, no cookies are used, and no analytics are tracked. The API is stateless — each request is independent with no session history. If you access this API through a ChatGPT Custom GPT, your text is also subject to OpenAI's privacy policy and data handling practices.

For questions, open an issue at [github.com/rezzedai/voicekeeper](https://github.com/rezzedai/voicekeeper/issues).
